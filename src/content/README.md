# Content Workspace

This directory is reserved for Astro's runtime content collections.

Do not write posts or poems directly in this repository. The `blog/` and `poetry/`
folders are generated from the external content repository before `pnpm dev` and
`pnpm build`, and are ignored by Git.

Write long-term content in:

```text
https://github.com/mitatis/zik-trinity-content
```
